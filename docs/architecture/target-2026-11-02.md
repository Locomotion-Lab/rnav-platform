# 精简平台目标与执行计划（2026-11-02）

此文替代 11 月 1 日方案中“保留监控、采购”和“默认同进程”的后续目标；原审计及验证记录作为历史证据保留。

## 模块与部署

| 逻辑模块 | 现有目录 | 职责与部署 |
| --- | --- | --- |
| rnav-web | apps/web | 独立 Next 进程；腾讯云官网、Console、AI 入口；不持有主库凭证 |
| rnav-backend | server | 独立 Express、版本化 REST、账号/权限/成员/资产/文件；Mac Docker |
| rnav-agent | 未来独立服务 | Mac；服务身份与用户授权交集调用业务 API，不接触主库 |
| rnav-miniapp | 暂不创建空工程 | 未来通过同一 API 及独立认证适配接入 |

云端 public reader 只读持久化发布版本，图片/PDF 原文件随版本发布。内部请求经同源 Next API 转发或 Nginx 私网网关；不暴露 PG、Mac 内网端口。Mac 是内部唯一写源；公开副本没有回写能力。

## 顺序与验收

1. 移除 Monitor/Procurement 页面、API、服务、导航、WebSocket、离线检测、运行配置和工具任务；解除 Express 对 Next 的运行时/构建依赖；独立镜像与构建。旧 API 返回 404，无新的遥测写入进程。核心权限/成员/设备回归通过。
2. 建立版本化 REST 合约与公开发布闭环：一致性公开投影、确认发布、快照/媒体清单与校验、云端原子版本激活、失败保留上版。验证 backend 停止且 web 重启后所有公开页、成员详情、图片和 PDF 可读。
3. StorageProvider 本地/COS 兼容、私有文件授权读取、持久卷与联合备份；禁止直接把整个文件目录公开。已上传 COS 地址先保留，不批量改 URL 或删除对象。
4. 私网通道、网关限时/转发头/Session/CSRF 验收；受限 PG 应用角色、生产数据恢复演练与确切切换单。任何生产写入/服务操作/部署前等待明确确认。

不为完成阶段而引入完整 Agent、向量库或微信工程。每阶段记录实际通过和未验证项。

## 退休模块与历史保护

删除的是运行代码，不是数据。42 个已应用 SQL 的内容和 checksum 保持不变，暂不提供 DROP/TRUNCATE/对象删除迁移。`scripts/db` 的旧导入工具是历史恢复工具，保留但不用于新部署导入；采购专用抓取与导入任务移除。

当前跨域引用包括：资产的 source_procurement_request_id；采购对 users 的作者/审批人 FK；采购 catalog 图片。历史成员删除阻断、媒体引用保护必须保留，否则界面移除后可能误删历史人员/文件。资产已有采购来源 FK 原样保留；新导入不再接受采购来源参数。权限解析只承认当前权限，历史 DB 权限/模板不删除、不再展示或赋予。

归档后续单独审批：在正式切换和观察期通过后，先创建加密 full dump、校验并隔离恢复；导出 retired 表、计数、FK、对象引用清单和 SHA-256，存异地只读归档。先将跨域引用改为归档标识并验证设备/账号/媒体生命周期，再决定删除退休表；不能 CASCADE 删除。COS 与本地文件只有确认不被核心表、公开历史版本或归档引用，且保留期结束后才可单独清理。回滚前保留新主库写入，禁止直接切回陈旧可写云库。

## 公开发布与安全边界

公开成员沿用 public_visible/public_fields，资产沿用 public profiles 和 public_visible 规格；不导出 users、session_tokens、system_secrets、内部笔记或私有文件。公开投影需在一致性事务内读取。发布包先预览差异，再明确批准；云端只接收已核实版本的文件包，拒绝非法路径、缺失媒体和错误哈希，原子激活。

云端绝不在 public reader 故障时回退主库；完整保留上一个版本以供恢复。媒体必须物化到发布包，不依靠 Mac/COS 临时可用性；审批包只能包含投影引用的媒体，不能递归拷贝私有目录。正式网络传输使用 Mac 主动出站的受限 SSH/私网；生产账号/密钥配置不进入仓库。

## 迁移门槛

基线生产仍为旧系统，开发分支的移除不会自动停用生产监控/采购。变更单必须明确旧设备请求退役、用户通知、最终备份时间、COS 清单、发布版本、恢复验收、冻结/切换/回滚命令与窗口。Mac 常开/断电恢复和异地备份是上线条件，不在本次擅自设置。
