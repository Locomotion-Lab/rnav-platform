# 老师论文同步与公开展示

老师的论文来源由控制台的「对外展示信息管理 → 论文库 → 老师论文来源」维护。只有成员资料标记为教师、OpenAlex 作者已核验并开启同步的来源会进入同步任务。成员个人资料保留基本身份和公开展示选项。论文作者以原作者名单为准，编辑可以将作者与已有成员关联并确认高亮。

1. 在系统设置的论文同步项配置 OpenAlex 与 Crossref 和全局开关。API Key 只在服务端读取，控制台仅显示掩码。
2. 在论文库选择老师，核验 OpenAlex 作者及同步年份，开启该来源或立即同步。
3. 审核候选。来源 ID 和 DOI 用于去重，重名或可能重复时由编辑核实。接收论文后，核实老师归属并在论文编辑器中勾选公开展示。未确认的历史论文保留供复核。
4. 根据姓名建议确认作者的成员关联。官网只高亮关联且公开展示姓名的成员。
5. 预览并发布公开版本。旧论文复核完成后按[云端运维文档](architecture/cloud-operations.md)启用筛选。

`npm run scholarly:sync` 可手动执行同一任务。同步任务通过 PostgreSQL advisory lock 避免重叠。云端定时任务见 `deploy/systemd/rnav-scholarly-sync.service` 和同名 timer，正式替换前保留线上原有 unit。

`npm run scholarly:backfill` 仅为有 DOI 的人工论文补充来源标识。历史成员同步表和既有关系保留，旧同步及重置操作可从提交 `70111be` 查阅。
